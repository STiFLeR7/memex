# memex v0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Evolve memex into a production-grade team context engine with multi-repo support, confidence-weighted write discipline, and HTTP/SSE transport.

**Architecture:** Transition to a "Unified Central Hub" model where a single global daemon manages multiple repository observers and serves an authenticated HTTP/SSE MCP server alongside the standard stdio transport.

**Tech Stack:** Python 3.11+, uv, Neo4j, Graphiti, tree-sitter, FastAPI, uvicorn, standard MCP SDK.

---

**Goal:** Implement the corroboration logic where agent decisions start at 0.6 confidence and reach 1.0 only when a subsequent commit touches the same module/symbol with a matching rationale.

```python
    text: str

    corroborated: bool = False
    corroboration_commit: Optional[str] = None
```

- [ ] **Step 2: Add validation for `confidence` and `source`**
```python
    @field_validator("confidence")
    @classmethod
    def confidence_in_range(cls, v):
        return max(0.0, min(1.0, float(v)))

    @field_validator("source")
    @classmethod
    def source_must_be_valid(cls, v):
        if v not in ("agent", "watcher"):
            raise ValueError(f"invalid source: {v}")
        return v
```
