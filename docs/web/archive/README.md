# Superseded website design (August 2026)

The first website direction: a light, Swiss-grid editorial layout
(`--bg:#F5F4F1`), built as a single hand-written HTML file.

Replaced in October 2026 by the memex v1 brand (airy paper, quiet ink, teal
and lime glass; `brag-output/brand/`), implemented as a Next.js app in
`memex-site/` and deployed to https://memex.stifler.in. It is light by
default, with a dark theme behind a toggle.

| File | What it is |
|---|---|
| `2026-08-swiss-prototype.html` | the light-theme single-file build |
| `2026-08-creative-direction.txt` | its art direction brief (written against the working name "Lumex") |

Kept as design history, not as a reference. `../CONTENT.md` remains the
editorial source; its section 00 describes the shipped v1 page.
