Temporal validity

Knowledge is stored with the conditions that can make it less useful.

Confidence is calculated at query time from base confidence, validation status, and time since reinforcement. The field beside each state is driven by the same formula.

validated: base × exp(-0.005 × days), floor 0.7
unvalidated ≤30d: base × exp(-(ln 2/30) × days)
older unvalidated: decays faster, capped at 0.5
Created

What it is not

Not ordinary RAG

Results are constrained by repository/project scope and active validity. The graph has typed entities, relation history, confidence, and write semantics.

Not a vector database product page

Graphiti search is one layer. The contract is repository context, provenance, and temporal state — not embeddings alone.

Not generic chat memory

An MCP client must request context or invoke writes. memex does not claim automatic universal recall before every response.

Not a coding agent

memex exposes information and governed graph writes. It does not own an editor or generate a patch.

Operating constraints

Scoped graph retrieval

Read tools accept repository or project scope rather than guessing across repositories.

Explicit write governance

Decision and Problem records are open for their tools; structural records are locked.

Local and team modes

Local Docker runs Neo4j; team compose keeps Neo4j inside the Compose network.

External dependency boundary

Gemini is used for configured synthesis. This page does not claim no data leaves a machine.

Questions the code can answer

How does memex decide what is current?

Live edge traversals filter expired_at IS NULL. Confidence is calculated from stored anchors at read time. Superseded material is excluded from ordinary engineering-context selection unless historical knowledge is requested.

What is automated, and what is written back deliberately?

Watcher events automate structural extraction; commit synthesis requires Gemini configuration. Agents or humans record decisions/problems, resolve problems, corroborate/supersede decisions, invalidate edges, and validate decisions through review.

What can an agent get before changing code?

It can request project, symbol, decision, problem, search, stale, briefing, or provenance-aware engineering context. Results depend on real graph state; memex does not fabricate missing evidence.

What is deliberately not claimed?

No customer metrics, benchmark wins, token-saving percentages, automatic universal memory, native integrations, or future roadmap features appear as showcase claims.
