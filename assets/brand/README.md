# memex brand kit (v1.0.0-rc.1)

The full board is `memex-brand-board.jpg`.

**Logomark:** `mark.svg`. Two offset rounded squares: teal is what the agent was told, lime is what the code says now, and the white overlap is the context that still holds. Use `mark-mono.svg` on light single-colour grounds and `mark-white.svg` on dark ones.

**Colours:**

| Name | Hex |
| --- | --- |
| Teal | `#00B3B5` → `#7FDDE0` |
| Lime | `#8EDC5A` → `#E6F8C8` |
| Ink | `#111417` (secondary `#4A5157`, `#8A9399`) |
| Paper | `#F7F9F8` |

**Type:** Stack Sans Headline (200, 300, 650) for display and text, DM Mono for code.

**Files:**
- App icons: `icon-light-1024.png`, `icon-night-1024.png`.
- Favicon: `favicon-32.png`.
- Mark as a transparent PNG: `mark-512.png`.
- Social preview: `social-card-1200x630.png`. Upload it under Settings → General → Social preview; GitHub has no API for that setting.

Clear space around the mark equals its offset (140 of 512 units). Minimum size is 16 px for the mark and 96 px wide for the lockup.
